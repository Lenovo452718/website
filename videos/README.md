# Product Videos

Place product video files in this folder.

## How to add a video to a product

1. Upload your `.mp4` video file here (e.g. `patte-elephant.mp4`)
2. In the **Admin panel**, edit the product and set the **Video URL** to:
   ```
   videos/patte-elephant.mp4
   ```
3. Save — the video will appear on the product page automatically.

## Notes

- Use `.mp4` format (H.264 codec) for best browser compatibility
- Keep videos under **50 MB** for fast loading
- Videos autoplay muted on product pages
- If no video is set (or it fails to load), the product images are shown instead
